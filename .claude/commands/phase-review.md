# .claude/commands/phase-review.md

Review completion status of a project phase.

Arguments:
$ARGUMENTS

---

# Instructions

Review the specified phase.

Determine whether phase exit criteria have been met.

Check:

1. Compilation status
2. Tests
3. Benchmarks
4. Profiling reports
5. Documentation
6. Deliverables

Produce:

# Phase Review

## Completed Work

## Missing Work

## Validation Status

## Benchmark Status

## Documentation Status

## Exit Criteria Checklist

[ ] Criterion 1

[ ] Criterion 2

...

## Verdict

PASS

or

FAIL

If FAIL:

Provide the minimum work required to pass.

If PASS:

Recommend the next phase.
