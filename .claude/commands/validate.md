# .claude/commands/phase-start.md

Start a new project phase.

Arguments:
$ARGUMENTS

---

# Instructions

You are beginning a new implementation phase.

Before writing code:

1. Determine the target phase from $ARGUMENTS.

2. Read:

   * PROJECT_SPEC.md
   * TASK_BREAKDOWN.md
   * IMPLEMENTATION_RULES.md
   * ARCHITECTURE.md
   * AGENT.md

3. Identify:

   * phase objectives
   * required deliverables
   * exit criteria

4. Produce a plan before writing code.

The plan must contain:

## Phase Goal

## Required Tasks

## Dependencies

## Validation Strategy

## Benchmark Strategy

## Risks

## Definition of Done

Do NOT implement code yet.

Wait for approval after presenting the plan.

Output format:

# Phase Analysis

...

# Execution Plan

...

# Awaiting Approval
